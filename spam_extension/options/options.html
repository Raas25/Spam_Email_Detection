Spam & Phishing Email Detector: Settings

Analysis backend

The FastAPI backend from this project, normally http://127.0.0.1:8000. The extension sends the opened email's text, links, images and attachments to it for analysis.

What to analyze

When off, attachments are judged by name and type only.

In Gmail

Privacy

Emails are only analyzed when you start a scan (or turn on automatic scanning). Content goes only to the backend above; this extension does not use external AI services. Link reputation (Google Safe Browsing) is used only if the backend operator configures an API key, and then only link addresses are sent to Google.
